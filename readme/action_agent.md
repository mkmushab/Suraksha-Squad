# suraksha_action_agent

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Epistemic Skeptic cross-checker and citizen protective action specialist uAgent used by **`suraksha_concierge`**.

- Cross-checks contradictions across specialist findings (e.g., valid `@oksbi` handle or `https://` TLS certificate used in a scam) and states honest offline verification boundaries.
- Generates ready-to-file **1930 / `cybercrime.gov.in`** complaint, **Bank Nodal Officer** freeze email, and **Hinglish Family WhatsApp Alert** drafts.

**Inter-agent protocol `suraksha-action-a2a` 1.0.0:** `SkepticActionRequest` → `SkepticActionResponse`.
